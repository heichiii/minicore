# M2 acceptance

Run the automated QEMU checks with:

```sh
make test
```

The target boots with both 256 MiB and 32 MiB of RAM and requires `M2 PASS`
from each run.  The in-kernel checks cover:

- allocation and release of physical pages;
- Sv39 `map`, `query`, `protect`, and `unmap`;
- recursive page-table reclamation with an exact free-page count check;
- writing through a new mapping and faulting after it is unmapped;
- rejecting a write to `.text`;
- faulting on the kernel-stack guard page;
- continuing to use UART and traps after the final `satp` switch.

Expected final output includes `M2 SATP PASS`, three classified page faults,
`M2 VM PASS`, and `M2 PASS`.
